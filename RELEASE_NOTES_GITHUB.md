# HSK Companion v1.2.1 — Public Android beta

**Free, unofficial HSK 1–2 study app**. No accounts, tracking, advertisements, or required donations.

- Focused Today / Learn / Practice / Progress / Settings navigation
- Mandarin vocabulary, grammar, contextual sentences, tone exercises and two-speaker dialogue practice
- Blue-and-warm-orange design, with light and dark modes
- Spaced reviews, progress backup/restore, optional local reminder notifications
- Optional **Support development** link in Settings (only when the publisher configured an external support page)

**Install:** download the `HSK_Companion_v1.2.1_release.apk` asset on Android, then allow your browser or Files app to install from this source. Only use the official project repository's release links.

**Updates:** install a newer release signed with the SAME maintainer certificate. If you installed an earlier debug-signed build, first export a progress backup in Settings. Never uninstall without backing up your progress.

**Privacy:** Study progress is stored on your phone. A donation link, when configured, opens a separate website; that provider's terms apply. See PRIVACY_POLICY.md.

**Disclaimer:** Unofficial learning resource. Not endorsed by HSK exam authorities. Practice tests are not official exams. Audio quality and Mandarin tones need editorial verification.
