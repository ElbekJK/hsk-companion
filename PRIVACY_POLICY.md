# HSK Companion — Privacy Policy (public beta)

Last updated: 6 November 2026.

HSK Companion is an offline-first, unofficial Chinese-language learning application. The Android application does not require registration or an account.

## Data handled by the app
- Your study progress, saved words, tone preferences, theme preferences, quiz history, and review schedules are stored locally on your Android device using app preferences.
- If you choose to export a backup, a JSON copy is saved to a location you select using Android's document picker. The file is unencrypted. Keep it private. Restoring a backup requires your confirmation.
- If you enable reminders, Android may display a local notification for overdue vocabulary. HSK Companion does not transmit your progress to a server for this purpose.
- The app contains no advertising SDK, analytics tracker, or developer-operated user database.

## Audio
- Lessons may play pre-generated Mandarin MP3 recordings bundled into the application. Synthesis using Microsoft Azure Speech is performed by the developer before publication; the Android application does not send your lesson data or credentials to Azure.
- When bundled speech is unavailable, the app uses the text-to-speech engine installed on your device. That engine may use network services governed by its own provider's privacy terms.

## Optional support links
- If configured by the maintainer, Settings shows a voluntary **Support development** link. Tapping it opens an external browser and leaves HSK Companion. Any payments and data you provide are handled by that external service under its own privacy policy. There are no paid features or required donations in HSK Companion.

## Data removal
- You can delete local HSK Companion data using Android's app storage controls or by uninstalling the application. Back up your study progress first if needed.

## Contact and changes
- Contact the project maintainer through the GitHub repository's Issues tab. This policy will be updated if future versions add server features or change data handling.
